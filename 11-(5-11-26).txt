LTRIM FUNCTION:-
======================
1.LTRIM FUNCTION IS USED TO TRIM CHARACTER FROM 
LEFT SIDE OF A COL/ EXP.

2. IT ACCEPTS 2 PARAMETER 1 IS A COL/ EXP,  
   2ND IS A   TRIMMING CHARACTER BUT IT OPTIONAL TO TAKE.

3. IF WE DONT TAKE 2 PARAMETER THEN IT WILL TRIM SPACE FROM COL/EXP   

4. IT WILL TRIM CHARACTER UNTIL A NEW CHARACTER GET
             
             
SELECT '##GEEK' , LTRIM ('##GEEK' , '#') FROM DUAL;              

SELECT '##*GEEK' , LTRIM ('##GEEK' , '#') FROM DUAL;      
 
SELECT 'GEEK' , LTRIM ('GEEK' , 'G') FROM DUAL;      
              
SELECT 'GEEKG' , LTRIM ('GGGGGGEEKG' , 'GE') FROM DUAL;      
              
SELECT ENAME, LTRIM (ENAME, 'A')  FROM EMP;
 
 
SELECT 'GEEKG' , LTRIM ('   GEEKG') FROM DUAL;      
 
RTRIM FUNCTION:-
======================
1.RTRIM FUNCTION IS USED TO TRIM CHARACTER FROM 
RIGHT SIDE OF A COL/ EXP.
2. IT ACCEPTS 2 PARAMETER 1 IS A COL/ EXP,  2ND IS A 
      TRIMMING CHARACTER BUT IT OPTIONAL TO TAKE.
3. IF WE DONT TAKE 2 PARAMETER THEN IT WILL TRIM SPACE FROM COL/EXP   
4. IT WILL TRIM CHARACTER UNTIL A NEW CHARACTER GET 
 
 SELECT RTRIM ('NARAYANA' , 'A') FROM DUAL;
 
 SELECT RTRIM ('NARAYANA' , 'NA') FROM DUAL;
 
 SELECT SAL, RTRIM (SAL, 0) FROM EMP;

 TRIM
=========
1. TRIM FUNCTION IS USED TO TRIM CHARACTER EITHER FROM LEFT 
SIDE OR RIGHT SIDE OR BOTH SIDE OF A COL / EXP.

2. TRIM WITH LEADING REMOVE CHARACTER FROM LEFT SIDE OF A
COL /EXP.

3. TRIM WITH TRAILING  REMOVE CHARACTER FROM RIGHT SIDE OF A
COL /EXP.
4. TRIM WITH BOTH  REMOVE CHARACTER FROM BOTH  SIDE OF A
COL /EXP BUT BOTH IS OPTIONAL TO TAKE.

5. TRIM SET SHOULD HAVE ONLY ONE CHARACTER

6.TRIM BY DEFAULT REMOVE  SPACE FROM BOTH SIDE.
 
 
 SELECT 'NARAYANAN' , TRIM('N' FROM 'NARAYANAN') FROM DUAL;
 
 SELECT 'NARAYANAN' , TRIM('NA' FROM 'NARAYANAN') FROM DUAL;
 
--Trim set should have only one character 
                
 SELECT 'NARAYAN' , TRIM(LEADING 'N' FROM 'NARAYAN') FROM DUAL;
 
 SELECT 'NARAYAN' , TRIM(TRAILING 'N' FROM 'NARAYAN') FROM DUAL;
 
  SELECT 'NARAYAN' , TRIM(BOTH 'N' FROM 'NARAYAN') FROM DUAL;

REPLACE :-
===========
1. REPLACE FUNCTION IS USED TO FIND AND REPLACE A CHARACTER .
2. IT ACCEPTS 3 PARAMETER, 1ST PARAMETER COLUMN/ EXP, 
   2ND PARAMETER FINDING CHARACTER,    3RD PARAMETER REPLACE CHARACTER.
3. 3RD PARAMETER IS OPTIONAL TO USE. IF WE DONT TAKE 3RD PARAMETER THEN
      REMOVE FINDING CHARACTER FROM COL/EXP.
4. REPLACE FUNCTION REPLACE PATTERN BY PATTERN. 
 
 
 SELECT REPLACE ('ORACLE' , 'O' , 'K') FROM DUAL;
 
 SELECT REPLACE ('NARAYANA' , 'A' , 'K') FROM DUAL;

TRANSLATE:-
============
1. TRANSLATE FUNCTION IS USED TO FIND AND TRANSLATE A CHARACTER.

2.IT ACCEPTS 3 PARAMETER, 1ST PARAMETER IS A COL/EXP, 2ND IS A FINDING CHARACTER,
   3RD IS A TRANSLATE CHARACTER & ALL 3 PARAMETERS ARE MANDATORY.
   
3. IT TRANSLATE CHARACTER BY CHARACTER.    
 
 SELECT TRANSLATE ('NARAYANA' , 'A', 'Z') FROM DUAL;
 
 SELECT TRANSLATE ('NARAYANA' , 'NA', 'KZ') FROM DUAL;

 SELECT TRANSLATE ('NARAYANA' , 'NA', 'K') FROM DUAL;
