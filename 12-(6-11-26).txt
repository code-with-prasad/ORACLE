 NUMBER FUNCTION
 ====================
 
These Functions Accept Numeric Input and Return Numeric Values as Output.

1. ROUND:-
========
1.Round function gives round UP value.
2.it always do round up, if value is more than   or equal to 5 
3.It accepts 2 aruguments but 2nd is optional.
4.if we pass 2nd parameter value then,   do round up after decimal value.

SELECT ROUND(25.5) FROM DUAL;

SELECT ROUND(25.2) FROM DUAL;                   
                   
SELECT ROUND(25.0) FROM DUAL;                   

SELECT ROUND(25.99) FROM DUAL;                       
                   
                   
SELECT ROUND (25.56, 1)   FROM DUAL;             
SELECT ROUND (25.52, 1)   FROM DUAL;   

SELECT ROUND (25.56, 2)   FROM DUAL;     
                                  
                                  
SELECT EMPNO, ENAME, SAL, ROUND(SAL/30) AS PER_DAY_SAL FROM EMP;                                  
                                  
                                  
 TRUNC
 =======
 1. trunc function removes decimal value and gives 
   actual value, it accepts two argument but 
   2nd  argument is optional
2.if we provide 2nd argument then trunc that particular 
  value after decimal.
  
 
SELECT TRUNC(25.3) FROM DUAL;  

SELECT TRUNC(25.9) FROM DUAL;                                    


SELECT TRUNC(25.12345, 2) FROM DUAL;                                       
                                  
SELECT EMPNO, ENAME, TRUNC(SAL/ 30,2) , ROUND (TRUNC(SAL/ 30,2))
FROM EMP;                                  
                                  
 CEIL FUNCTION
-------------------
CEIL FUNCTION RETURNS ROUND UP VALUE IRESPECTIVE OF DECIMALS. 


SELECT CEIL (20.56) FROM DUAL;

SELECT CEIL (20.26) FROM DUAL;

SELECT EMPNO, ENAME ,SAL, CEIL (SAL/30) , ROUND(SAL/30) FROM EMP; 

FLOOR FUNCTION
=================
FLOOR FUNCTION RETURNS LOWER  VALUE IRESPECTIVE OF DECIMALS.

SELECT FLOOR (23.56) FROM DUAL;

SELECT FLOOR (23.12) FROM DUAL;

POWER FUNCTION
=================
1.power function return values multipled by    no of times by 2ND PARAMETER exponent
2. The first parameter is base and 2nd is power.

SELECT POWER(10, 2) FROM DUAL;

SELECT POWER(10, 3) FROM DUAL;

SELECT EMPNO, ENAME, SAL, POWER (SAL, 2) FROM EMP;

ABS(ABSOLUTE FUNCTION)
======================
PROVIDE ALWAYS THE POSITIVE VALUE


SELECT ABS (-20) FROM DUAL;

SELECT ABS (20) FROM DUAL;

SELECT ABS (0) FROM DUAL;

SELECT EMPNO, ENAME, SAL, COMM, ABS (SAL - NVL(COMM,0) )  FROM EMP;

SIGN FUNCTION
-------------------------
It returns sign ,specification of a number.

if n<0 returns -1
if n=0 returns 0
if n>0 returns 1


SELECT SIGN (10) , SIGN(-10), SIGN (0) FROM DUAL;
