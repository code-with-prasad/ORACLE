BETWEEN OPERATOR
===================
WHEN WE WANT TO SEE RANGE BASED DATA THAT TIME WE CAN USE BETWEEN OPERATOR.
RANGE ALWAYS STARTS FROM LOWER TO UPPER.


Q:- DISPLAY EMP INFO WHOSE SALARY IS FROM 2000 TO 3000?

SELECT * FROM EMP WHERE SAL BETWEEN 2000 AND 3000;

SELECT * FROM EMP WHERE SAL BETWEEN 3000 AND 2000;--NOT RECOMENDED

SELECT * FROM EMP WHERE SAL >=2000 AND SAL<=3000;

Q:- DISPLAY EMP INFO WHO JOINED IN THE YEAR 82 ?

SELECT * FROM EMP WHERE HIREDATE BETWEEN '01-JAN-82' AND '31-DEC-82';

NOT BETWEEN
================
OPPOSITE OF BETWEEN

Q:- DISPLAY EMP INFO WHO JOINED NOT IN THE YEAR 82 ?

SELECT * FROM EMP WHERE HIREDATE NOT BETWEEN '01-JAN-82' AND '31-DEC-82';

LIKE OPERATOR
================
WHEN WE WANT TO SEARCH PARTIALLY DATA OF A COLUMN THAT TIME
WE CAN USE LIKE OPERATOR.

HERE 2 WILD CHARACTER USED 
  1.  % --> ANY CHARACTER
  2. _  --> SINGLE CHARACTER
  
Q:- DISPLAY EMP INFORMATION WHOSE NAME STARTS WITH K?

SELECT * FROM EMP WHERE ENAME LIKE 'K%';
  
SELECT * FROM EMP WHERE ENAME LIKE 'A%';

SELECT * FROM EMP WHERE SAL LIKE '5%';

SELECT * FROM EMP WHERE HIREDATE LIKE '03%';

Q:- DISPLAY EMP INFORMATION WHOSE NAME ENDS WITH H?

SELECT * FROM EMP WHERE ENAME LIKE '%H';

Q:- DISPLAY EMP INFORMATION WHOSE NAME CONTAINS WITH S?

SELECT * FROM EMP WHERE ENAME LIKE '%S%';

Q:- DISPLAY EMP INFORMATION WHOSE NAME CONTAINS WITH A AND S?

SELECT * FROM EMP WHERE ENAME LIKE '%A%S%';

Q:- DISPLAY EMP INFO WHOSE NAME CONTAINS 5 CHARACTER?

SELECT * FROM EMP WHERE ENAME LIKE '___';

Q:- DISPLAY EMP INFO WHOSE NAME CONTAINS 4 CHARACTER AND STARTS WITH F?

SELECT * FROM EMP WHERE ENAME LIKE 'F___';

 SELECT * FROM EMP WHERE ENAME LIKE  'AD%';

SELECT * FROM EMP WHERE ENAME LIKE '_A%';

ESCAPE
==========
WHEN WE WANT SEARCH ANY WILD CHARACTER THAT TIME SEARCH
WITH SPECIAL CHARACTER + WILD CHARACTER USING ESCAPE KEYWORD.


SELECT * FROM student_inf WHERE STD_NAME LIKE '%@%%' ESCAPE '@';

Q:-DISPLYA STD INFO WHOSE NAME ENDS WITH %?

SELECT * FROM student_inf WHERE STD_NAME LIKE '%#%' ESCAPE '#';


SELECT * FROM student_inf WHERE STD_NAME LIKE '%@_%' ESCAPE '@';

SELECT * FROM student_inf WHERE STD_NAME LIKE '%@_%' ESCAPE '@'
AND STD_NAME LIKE '%@%%' ESCAPE '@';

Q:- DISPLAY EMP INFO WHOSE NAME CONTAINS S AND COMM IS NULL?

SELECT * FROM EMP WHERE ENAME LIKE '%S%' AND COMM IS NULL;

ORDER BY CLAUSE
==================
1
3
5
9
2
1, 2, 3, 5,9-ASCENDING
9,5,3,2,1  -DESCENDING

ASC -> A -Z
        -> 0-9
        -> CALENDER
        
DESC -> Z- A
          -> 9-0
          -> REVERSE OF CALENDER


1. ORDER BY CLAUSE IS USED TO SORT DATA 
IN ASCENDING OR DESCENDING ORDER.

2. WE CAN DO SORTING BY COLUMN NAME, COLUMN POSITION,
    COLUMN ALIAS.
  
  INTERVIEW QUESTION  
3.ORDER BY IS THE LAST CLAUSE OF A SELECT STATEMENT.    

4. WE CAN APPLY  ORDER BY ON MULTIPLE COLUMNS .

5. WE CAN DO ORDER ON MULTIPLE COLUMN , FIRST IT WILL ORDER ON
    1ST COLUMN, 2ND COLUMN SO ON..

6.  A COLUMN CONTAINS NULL ALWAYS DISPLAY LAST IN CASE OF ASCENDING 
     BUT TOP IN CASE OF DESCENDING .  
7. TAKING ASC IS OPTIONAL .


SELECT * FROM EMP ORDER BY ENAME;
SELECT * FROM EMP ORDER BY ENAME ASC;

SELECT * FROM EMP ORDER BY ENAME DESC;
