SUBSTR
==========
1. SUBSTRING FUNCTION IS USED TO GET SPECIFIC VALUE FROM A 
    COLUMN OR EXPRESSION .
    
2. IT ACCEPTS 3 PARAMETER.

3. 1ST PARAMETER IS A COLUMN OR EXPRESSION , 2ND IS A STARTING POINT,
    3RD PARAMETER IS AN ENDING POINT.
    
4. 2ND AND 3RD PARAMETER TREATED AS m and n Position 

5. 1st and 2nd is mandatory but 3rd   IS OPTIONAL TO TAKE.
    IF 3RD IS NOT THERE THEN DISPLAY FROM STARTING POINT TO END OF THE STRING.

6. m CAN BE POSITIVE OR NEGATIVE, IF m is NEGATIVE THEN 
    SEARCH DATA FROM RIGHT TO LEFT & POSITIVE THEN 
    SEARCH FROM LEFT TO RIGHT
    
7. IF SEARCHING IS UNSUCCESSFULL THEN DISPLAY NULL.

8.n Can not be LESS THAN 1 , if so then display NULL

9. IF m IS 0 IT TREATED AS 1
