INSTR (INSTRING)
===============
1. INSTR FUNCTION IS USED TO DISPLAY NUMERICAL POSITION OF A CHARACTER.
2. IT ACCEPTS 4 PARAMETER , 1ST IS A COLUMN/EXPRESSION , 
    2ND IS SEARCHING CHARACTER, 3RD IS A STARTING POINT ,
    4TH IS A OCCURANCE
3. 3RD AND 4TH PARAMETER IS OPTIONAL.
4. BY DEFAULT IT SEARCH FROM 1ST POSITION.
5.m CAN be POSITIVE AND NEGATIVE BUT CAN  NOT BE ZERO.
6. IF 4TH PARAMETER IS LESS THAN 1 THEN ERROR
7. IF SEARCHING IS UNSUCESSFULL THEN DISPLAY 0.
