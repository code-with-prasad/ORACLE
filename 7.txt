INTERVIEW QUESTION

NULLIF
=======

1. NULLIF FUNCTION ACCEPT 2 PARAMETER AND  COMPARE THE PARAMETER VALUE
IF IT MATCHES THEN DISPLAY NULL, IF IT DOESNOT MATCH DISPLAY FIRST PARAMETER
VALUE.

2. DATA TYPE SHOULD MATCH BETWEEN PARAMETERS.

SELECT NULLIF (100, 200) FROM DUAL;

SELECT NULLIF (100, 100) FROM DUAL;

SELECT SAL, COMM, NULLIF (SAL, COMM) FROM EMP;

INTERVIEW QUESTION

COALESCE :-
==========
1. COALESCE FUNCTION IS USED TO PROVIDE FIRST NOT NULL VALUE
    AMONG PARAMETERS.
2. DATA TYPE SHOULD MATCH BETWEEN THE PARAMETERS.
3. IT ACCEPTS n NUMBER OF PARAMETERS.

SELECT COALESCE (NULL, NULL,100,200) FROM DUAL;

SELECT COALESCE (50,10,NULL, NULL,100,200) FROM DUAL;

SELECT MGR, EMPNO, COALESCE (MGR, EMPNO) FROM EMP;


SELECT COALESCE (NULL, 100) FROM DUAL;

SELECT NVL (NULL, 100) FROM DUAL;

NESTED FUNCTION
===================
WHEN WE WANT TO WRITE A FUNCTION INSIDE ANOTHER FUNCTION IS 
KNOWN AS NESTED FUNCTION.

SELECT EMPNO, ENAME, SAL, COMM,SAL+COMM,  NVL2 (COMM, SAL, NVL(NULL,100) ) 
FROM EMP;

NOTE:- 1. HERE NVL IS THE INNER FUNCTION AND NVL2 IS THE OUTER FUNCTION
2. INNER FUNCTION EXECUTE FIRST THEN OUTER FUNCTION WILL EXECUTE.

SELECT  COALESCE ( NULL, NULL, NVL2( NULL, 100, 200 ) ) FROM DUAL;

SELECT NVL2( NULL, COALESCE ( NULL, NULL, 100 ) , 200+300 ) FROM DUAL

SELECT NVL2( NULL, 100 , 200+300 ) FROM DUAL;

ALIAS
=====
ALIAS IS AN ALTERNATE NAME FOR A DATABASE OBJECT OR COLUMN.

IT IS 2 TYPES :-
===========
1. COLUMN ALIAS
2.TABLE ALIAS

1. COLUMN ALIAS :-
================
1. COLUMN ALIAS RENAME THE COLUMN HEADER IN A TEMPORARY BASIS.

2. IT SHOULD BE  WRITTEN NEXT TO THE COLUMN NAME.

3. BETWEEN COLUMN AND ALIAS NAME WE CAN PUT AS KEYWORD BUT IT IS OPTIONAL TO USE.

4. COLUMN ALIAS CAN NOT BE USED IN WHERE CONDITION BUT CAN BE USED IN ORDER BY CLAUSE.

5. The alias contains space and special character such as ($,#) or is case senstive ,
enclose the alias in double quotation marks(" ")

CONCATENATION OPERATOR
=========================

1. WHEN WE WANT TO  COMBINE TWO OR MORE THAN TWO COLUMN(2 EXPRSSION)
    THAT TIME WE CAN USE CONCATENATION OPERATOR.
    
2. IT IS REPRESENTED WITH ||. 

Q:- DISPLAY EMPNO, ENAME, COMBINE SAL WITH COMM ?

SELECT EMPNO, ENAME, SAL || COMM FROM EMP;

SELECT EMPNO, ENAME, SAL || ',' || NVL(COMM,0) AS SAL_MERGE_COMM 
FROM EMP;

SELECT EMPNO, 'Mr.' || ENAME AS EMPLOYEE_NAME, SAL || ',' || NVL(COMM,0) AS SAL_MERGE_COMM 
FROM EMP;
