ORDER BY CLAUSE
==================
1
3
5
9
2
1, 2, 3, 5,9-ASCENDING
9,5,3,2,1  -DESCENDING

ASC -> A -Z
        -> 0-9
        -> CALENDER
        
DESC -> Z- A
          -> 9-0
          -> REVERSE OF CALENDER


1. ORDER BY CLAUSE IS USED TO SORT DATA 
IN ASCENDING OR DESCENDING ORDER.

2. WE CAN DO SORTING BY COLUMN NAME, COLUMN POSITION,
    COLUMN ALIAS.
  
  INTERVIEW QUESTION  
3.ORDER BY IS THE LAST CLAUSE OF A SELECT STATEMENT.    

4. WE CAN APPLY  ORDER BY ON MULTIPLE COLUMNS .

5. WE CAN DO ORDER ON MULTIPLE COLUMN , FIRST IT WILL ORDER ON
    1ST COLUMN, 2ND COLUMN SO ON..

6.  A COLUMN CONTAINS NULL ALWAYS DISPLAY LAST IN CASE OF ASCENDING 
       BUT TOP IN CASE OF DESCENDING .  
       
7. TAKING ASC IS OPTIONAL .


SELECT * FROM EMP ORDER BY ENAME;
SELECT * FROM EMP ORDER BY ENAME ASC;

SELECT * FROM EMP ORDER BY ENAME DESC;

SELECT * FROM EMP ORDER BY SAL DESC;

SELECT * FROM EMP ORDER BY 3 DESC;

CASE CONVERSION FUNCTION
==========================
WHEN WE WANT TO CONVERT UPPER TO LOWER OR LOWER TO UPPER THAT TIME WE CAN USE
CASE CONVERSION FUNCTION.

1.UPPER 2. LOWER  3.INITCAP

SELECT  UPPER ('hi') , LOWER ('HI') , INITCAP ('HI')  FROM DUAL;

SELECT ENAME,  UPPER(ENAME), LOWER(ENAME), INITCAP (ENAME) FROM EMP;


SELECT * FROM EMP WHERE LOWER(ENAME) = 'king';

SELECT * FROM EMP WHERE  ENAME = UPPER ('king');


SELECT UPPER('The '  || Ename||  '"s  Basic Salary  is Rupees  '|| Sal) FROM Emp
WHERE Job  IN( 'MANAGER',  UPPER('clerk')  ) 
ORDER BY Sal  DESC;
