APPLY ARITHMATIC OPERATION IN  SELECT STATEMENT
===============================================
+ , - , *, /

1. IN SELECT WE CAN ADD ADDITION, SUBSTRACTION, MULTIPLICATION, DIVISON .
2. IT FOLLOWS BODMAS RULE
3.	Multiplication and division take priority over addition and subtraction.(*/+-)
4.	Operators of the same priority are evaluated from left to right.
5.	To prioritize evaluation and to increase clarity parenthesis can be implemented.


SELECT 100 + 200 FROM DUAL;

SELECT 10*2*3  FROM DUAL;

SELECT 10+2*3  FROM DUAL;

SELECT (10+2)*3  FROM DUAL;

NULL
=====
1. NULL IS A UNKNOW VALUE / UNDEFINED VALUE & IT IS ABSENCE OF DATA.

2. ANY CALCULATION WITH NULL ARE NULL.

3. EACH NULL ARE NOT SAME.

4. NULL IS NOT EQUAL WITH 0

5. IT IS REPRESENTED BY NULL KEYWORD / ''

6. RDBMS MUST SUPPORT NULL VALUE

7.NULL ALWAYS COMPARE WITH IS KEYWORD

FUNCTION
===========
 Function is used to perform some task and return some value.
 
 FUNCTION ARE TWO TYPES
 
 1.ORACLE DEFINED FUNCTION :- THIS FUNCTION IS DEFINED BY ORACLE / PRE DEFINED.
 
 2.USER DEFINED FUNCTION :- THIS FUNCTION IS CREATED BY USER (DEVELOPER)
 
 1.ORACLE DEFINED FUNCTION :- 
 ==================================
   1.SINGLE ROW FUNCTION 2. AGGREGATE FUNCTION 3.WINDOW FUNCTION ETC..
  
1.SINGLE ROW FUNCTION:-
========================
1. IT APPLIES EACH ROW OF A COLUMN .
2. THIS FUNCTION RETURN VALUE BY EACH ROW.
3. SINGLE ROW FUNCTION CAN BE USED IN SELECT, WHERE , ORDER BY CLAUSE

EX:- NVL, NVL2, COALESCE, NULIFF ETC...

NVL FUNCTION
===============
1.  NVL FUNCTION IS USED TO CONVERT A NULL VALUE TO AN ALTERNATE VALUE.
2. IT ACCEPTS 2 PARAMETER.
3. 1ST PARAMETER IS A COLUMN /EXPRESSION,      2ND PARAMETER IS A ALTERNATE VALUE
4. DATA TYPE SHOULD MATCH.

SELECT EMPNO, ENAME, SAL, COMM,  NVL( COMM , 100 ) FROM EMP;

Q:- DISPLAY EMPNO, ENAME, SAL, COMM, SAL + COMM  ( TOTAL INCOME ) ;

SELECT EMPNO, ENAME, SAL, COMM, SAL + COMM FROM EMP;

SELECT EMPNO, ENAME, SAL, COMM, SAL + NVL ( COMM, 0)  FROM EMP;

SELECT EMPNO, ENAME, SAL, NVL (COMM,0) ,  SAL + NVL ( COMM, 0)  FROM EMP;


SELECT EMPNO, ENAME, SAL, COMM,  NVL( COMM , 'HELLO' ) FROM EMP; --ERROR STATEMENT


SELECT  NVL( NULL , 100 ) FROM DUAL;
NVL2:-
======

1. NVL2 FUNCTION IS USED TO PROVIDE ALTERNATE VALUE,  FOR NULL AND NOT NULL.
 
 2. IT ACCEPTS 3 PARAMETER.
 
 3. 1ST PARAMETER IS A COLUMN / EXPRESSION , 2ND PARAMETER IS A 
      ALTERNATE VALUE FOR NOTNULL,      3RD PARAMETER IS A ALTERNATE VALUE FOR NULL.
 4. DATA TYPE SHOULD MATCH BETWEEN THE PARAMETERS


SELECT EMPNO, ENAME, SAL, COMM, NVL2(COMM, 200, 0 ) FROM EMP;

Q:- DISPLAY EMPNO, ENAME, SAL, COMM, PROVIDE 20% OF SALARY FOR NO COMMISSION, 
10% OF SALARY FOR COMMISSIONED EMPLOYEE?

SELECT EMPNO, ENAME, SAL, COMM, NVL2 (COMM,   SAL*0.10,   SAL*0.20) FROM EMP;
